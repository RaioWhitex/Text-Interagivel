# 💬 Testimonial Card UI

Uma interface moderna de cartão de depoimento desenvolvida com foco em simplicidade, legibilidade e experiência do usuário, utilizando um layout elegante para destacar textos, links e informações pessoais de forma organizada.

---

## 📸 Preview do Projeto

Interface contendo:

- Cartão de depoimento centralizado
- Texto descritivo em destaque
- Links personalizados dentro do conteúdo
- Layout limpo e moderno
- Design responsivo e minimalista

---

## ✨ Tecnologias Utilizadas

- **HTML5**
- **CSS3**

---

## 🎨 Características do Design

- Interface moderna e minimalista
- Cartão com bordas arredondadas
- Tipografia elegante e legível
- Destaque visual para links
- Espaçamento equilibrado para melhor leitura
- Layout centralizado
- Design clean e profissional
- Estrutura responsiva

---

## 🚀 Objetivo do Projeto

Praticar habilidades de desenvolvimento front-end através da criação de um cartão de depoimento moderno e responsivo, explorando conceitos de tipografia, espaçamento, alinhamento, estilização de links e organização visual utilizando HTML e CSS.

---

## 📚 Funcionalidades

- Exibição de textos informativos
- Destaque para links importantes
- Estrutura simples e organizada
- Layout responsivo para diferentes dispositivos
- Experiência de leitura otimizada
- Fácil personalização de conteúdo
